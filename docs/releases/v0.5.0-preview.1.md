# Vela 0.5.0 Preview

Change an environment's Wine engine without reinstalling its Windows applications.

## Changes

Open an environment's **Settings → Change Wine engine…**, select another registered engine, and confirm. Vela stops that environment, saves a prefix/settings backup, updates it with the selected Wine engine, checks Windows execution, and retains its programs, files, shortcuts, variables, scale, and paths.

- Automatically attempt recovery if the new engine fails its update or execution check.
- Use **Restore before engine change…** to return to the previous prefix and saved settings. Replaced files are retained in the backup folder.
- Recover an interrupted operation from settings; launching is blocked until recovery completes.
- Show a separate warning when the selected engine cannot run 32-bit applications.
- Prevent launch, stop, settings, and shortcut operations from using stale engine selection during a change.

Save work first: Windows programs in the selected environment will close. Keep the old engine installed for restore. Backups use disk space and remain until manually removed or the environment is permanently deleted. External files reached through host symlinks are not copied. Only the most recent pre-change backup is exposed by the restore button. Changing engines does not convert pure 32-bit prefixes or guarantee compatibility with every installed application.

- `SHA256SUMS` — checksums for both ZIP archives.

Wine engines are installed separately. English and Russian are supported, with device languages used by default. Preview builds use local ad hoc signing and are not notarized. Avoid opening a library with an interrupted engine change in an older Vela version.

## Validation

Twenty-four Rust unit tests and two protocol tests passed, covering rollback, interrupted recovery, data preservation, path containment, and engine-selection races. The Swift 6 build and translation resource checks passed.

In a disposable real Wine environment, Intel → ARM64/FEX → Intel changes preserved an installed original x64 test application, data, shortcuts, variables, and the 192-DPI registry setting. The Intel path also ran a 32-bit Windows command. Backup restore returned the native engine and previous saved state while retaining post-switch files separately. Existing user environments were not switched during validation.
