# Vela 0.4.2 Preview

Keep Intel Wine alongside the native engine as an explicit fallback for 32-bit Windows applications.

## Changes

- Label Intel WoW64 engines **Fallback for 32-bit apps** in the engine library, environment creation, launcher installation, and environment header.
- Explain that the fallback supports both 32-bit and 64-bit Windows apps through Rosetta on Apple Silicon.
- Retain the native ARM64/FEX engine first in the selection order. Existing environments keep their current engine.
- Clarify that keeping an Intel engine does not guarantee its availability in future macOS versions. The current native runtime still supports 64-bit Windows apps only.

This release labels an existing compatible engine; it does not include or automatically download Wine binaries. Add a compatible Wine engine separately. No duplicate engine or additional user environment is created.

## Downloads

- `Vela-0.4.2-preview.zip` — Apple Silicon application, version 0.4.2, build 8.
- `Vela-0.4.2-source.zip` — source and vendored Rust dependencies with license notices.
- `SHA256SUMS` — checksums for both ZIP archives.

English and Russian are supported, with device languages used by default. Preview builds use local ad hoc signing and are not notarized.

## Validation

The Swift 6 application build, translation resource checks, and local signature verification passed. The fallback label and both engine choices were checked in the running app. The same Intel Wine engine previously passed real Windows command execution through both `system32` and `syswow64`; this update changes presentation only.
