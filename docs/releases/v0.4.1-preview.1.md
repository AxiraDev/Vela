# Vela 0.4.1 Preview

This update makes Wine engine selection clearer.

## Changes

- Replace engine dropdowns with selectable cards in environment creation and launcher installation.
- Show Windows application support prominently: **32-bit and 64-bit**, **64-bit only**, or **32/64-bit support unverified**.
- Identify the Mac engine separately as **Apple Silicon (ARM64)** or **Intel (x86_64)**, with an explicit Rosetta label.
- Show the same capability summary in the engine library and environment header.
- Disable engine cards known to be incompatible with a launcher's required 32-bit installer support.
- Detect Intel WoW64 support from matching Windows module headers when the runtime has no explicit capability declaration. Explicit restrictions always take priority; a Mac architecture alone does not establish 32-bit Windows support.

A 64-bit Intel Mac engine can run both 32-bit and 64-bit Windows applications through WoW64. ARM64/Intel and Windows application bitness are presented as separate properties.

The app supports English and Russian and follows device languages by default. A compatible Wine engine is required separately. Preview builds use local ad hoc signing and are not notarized.

## Validation

Nineteen Rust unit tests and two protocol integration tests passed, including missing/malformed WoW64 modules, explicit restriction precedence, and separate Mac/Windows architecture handling. Translation resource checks passed for 222 keys.

The installed Intel Wine build initialized a disposable environment and ran Windows commands through both `system32` and `syswow64`, with shortcuts, arguments, environment variables, working directories, and logs checked. Only that test environment was stopped.

These checks establish the tested build's basic 32/64-bit execution paths, not compatibility with every application. The experimental ARM64/FEX runtime retains its 64-bit-only restriction. Many launchers need 32-bit support even if their client is 64-bit.

Vela's manager and interface use MIT. External components retain their own licenses. Optional development support is available through [Boosty](https://boosty.to/axira_dev/donate).
