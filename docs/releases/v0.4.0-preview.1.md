# Vela 0.4.0 Preview

Vela is a free, open-source Wine manager for macOS, built with SwiftUI and Rust.

This update adds environment deletion and a fully bilingual interface.

## Changes

- Delete an environment from its Settings tab or the sidebar context menu, with confirmation and a stop scoped to that environment's Wine server.
- Restore deleted environments from Vela Trash with their Windows files, shortcuts, and settings intact.
- Permanently delete an environment's prefix, cached installers, and operation logs after a separate confirmation. Wine engines and files outside the environment are kept.
- Switch between English, Russian, and System default in App settings or the standard macOS Settings window.
- Follow the device's preferred languages on first launch, with English as the fallback when none is supported. Explicit choices persist and apply immediately.
- Translate interface labels, launcher catalog descriptions, dialogs, progress messages, and core errors. Wine and Windows applications retain their own language settings.
- Serialize environment launch, initialization, and deletion with kernel-backed per-environment locks.

The ten-preset game launcher catalog, official downloads, automatic environment creation, and shortcut detection remain available.

## Deletion behavior

Deletion stops the environment's Windows programs, so unsaved changes can be lost. Vela Trash is separate from macOS Trash. Soft-deleted files remain in their original location and still use disk space until permanent deletion. Permanent deletion cannot be undone. Vela does not automatically empty its trash.

## Downloads

- `Vela-0.4.0-preview.zip` — Apple Silicon application, version 0.4.0, build 6.
- `Vela-0.4.0-source.zip` — source and vendored Rust dependencies with license notices.
- `SHA256SUMS` — checksums for both ZIP archives.

The application targets macOS 14.0 or later; validation used Apple M1 and macOS 26.5.2. Preview builds use local ad hoc signing and are not notarized.

**Wine is not included.** Add a compatible engine separately. Many launcher installers require 32-bit Windows support (WoW64); the experimental native 64-bit-only engine cannot run them. Launcher inclusion does not guarantee game compatibility, and games requiring Windows anti-cheat drivers may not work.

## Validation

Eighteen Rust unit tests and two JSON protocol integration tests passed. These include environment removal, recovery, file containment, failed-stop handling, and English/Russian core errors. A Swift check validated language negotiation, persistent-choice resolution, resource parity, and format arguments across 212 interface keys.

A disposable environment using the real native Wine engine passed stop, recoverable deletion, restore with saved data intact, and permanent removal while preserving an external sentinel file.

Read the README for setup, data storage, and preview limitations. Report reproducible issues with your Mac/macOS, Vela and Wine versions, application details, and redacted logs.
