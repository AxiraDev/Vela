# Vela 0.2.0 Preview

Vela is a free, open-source Wine manager for macOS, with a native SwiftUI interface and a Rust core.

This first preview provides manual control over Wine engines and separate Windows environments. Add an engine, create an environment, launch an installer or executable, and keep your application shortcuts and settings together.

## Highlights

- Multiple Wine engines and separate 64-bit environments.
- EXE/MSI launch, application shortcuts, launch arguments, and working directories.
- Wine configuration, Registry Editor, Windows console, and uninstaller access.
- Per-environment variables, DLL overrides, logs, and scoped stop.
- Windows interface scaling from 100% to 300%, with a Retina-friendly default for new environments.
- ARM64/Intel engine detection and Rosetta dependency labels.
- Experimental ARM64/FEX engine support for a locally validated x64 execution path.
- Vela application icon and optional Boosty support link.

## Before installing

The application archive is for Apple Silicon. The app deployment target is macOS 14.0; validation was performed on an Apple M1 running macOS 26.5.2.

**Wine is not included.** Install a compatible engine separately. The locally validated native Wine/FEX configuration requires macOS 26.5 or later and supports 64-bit Windows applications only. Its engine binaries are not included in these downloads.

The current interface is in Russian. The primary documentation is in English.

This is an early preview with local ad hoc signing. Developer ID signing, notarization, automatic engine updates, snapshots, and engine migration are not implemented. Graphics backend installation is not provided.

## Validation

Ten Rust unit tests and one JSON protocol test passed. The SwiftUI build and local app signature were checked. A separate experimental runtime initialized a fresh environment, applied 192 DPI, and ran an original external x64 PE fixture with `P_TRANSLATED=false`.

These are preview checks, not a guarantee of compatibility with a particular Windows application.

## Support and feedback
