# Vela 0.3.0 Preview

Vela is a free, open-source Wine manager for macOS, built with SwiftUI and Rust.

This preview adds a game launcher catalog. Choose an official Windows installer preset and a Wine engine; Vela downloads the installer, creates a separate environment, and opens the setup wizard. When the client executable appears in a known location, its shortcut is added automatically.

## Highlights

- Ten installer presets: Steam, Epic Games Launcher, GOG GALAXY, Battle.net, EA app, Ubisoft Connect, Rockstar Games Launcher, Amazon Games, itch.io, and Wargaming Game Center (EU).
- HTTPS downloads with restricted redirect hosts, progress, cancellation, and a 512 MiB file limit.
- Automatic environment creation, cached installers, client detection, and installer retry.
- Installer architecture requirements and rejection of known 32-bit installer / 64-bit-only engine mismatches.
- A Riot Client information card explaining the Vanguard limitation.
- Multiple Wine engines, application shortcuts, launch arguments, Wine tools, per-environment settings, logs, and Windows interface scaling from 100% to 300%.
- Native ARM64 / Intel engine labels, Vela's app icon, and optional [Boosty support](https://boosty.to/axira_dev/donate).

## Before installing

The application is for Apple Silicon, with a macOS 14.0 deployment target. Validation used an Apple M1 running macOS 26.5.2. The interface is currently in Russian; primary documentation is in English.

**Wine is not included.** Add a compatible engine separately. Many launchers use 32-bit bootstrappers and need WoW64. The experimental native Wine/FEX engine documented in this repository supports only 64-bit Windows applications and cannot run those bootstrappers. Vela never silently switches engines.

Finish each publisher's interactive setup wizard yourself. Launcher inclusion is not a guarantee that the client or its games work with Wine. Anti-cheat drivers and other Windows-only dependencies can prevent games from running. Riot Vanguard games are not offered for installation.

This preview uses local ad hoc signing. Developer ID signing, notarization, automatic engine updates, snapshots, engine migration, and graphics backend installation are not implemented.

## Validation and limits

Fifteen Rust unit tests and one JSON protocol test cover state handling, environment isolation, architecture checks, installer rejection, environment creation/retry, automatic shortcuts, and path containment. The native SwiftUI build and local signatures were checked. A separate Swift transport check downloads an official itch.io Windows installer through the allowed HTTPS redirects without running it.

These checks validate Vela's workflow; the full commercial launcher and game compatibility matrix has not been tested. The experimental native runtime's earlier x64 fixture results are documented separately.
