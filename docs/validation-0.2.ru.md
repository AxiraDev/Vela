# Проверка Vela 0.2

23 октября 2026 года; Apple M1, macOS 26.5.2. Ядро и интерфейс ARM64.

## Что изменено

- Архитектура движка читается из Mach-O, включая universal binaries.
- Wine и wineserver подбираются из одной сборки; сохранён путь через loader symlink.
- ARM64-движки первыми предлагаются в интерфейсе; Intel-движки помечены зависимостью от Rosetta.
- Возможности 32-битного режима объявляются явно; неподдерживаемый i386 EXE отклоняется до запуска.
- После wineboot ожидается асинхронное сохранение реестра до 20 секунд.
- Уже остановленное окружение не выдаёт ложную ошибку при остановке.
- Меню ярлыка получило дополнительный отступ справа; открытие меню проверено в интерфейсе.
- Масштаб Windows 100–300% меняется через реестр выбранного окружения.
  Новым окружениям на Retina предлагается 200%; открытые Windows-программы не завершаются.
- Wine получает необходимые переменные запуска без переноса идентификатора приложения-хоста.
- Добавлена собственная иконка Vela: PNG и набор ICNS для размеров 16–1024 px,
  подключённый через CFBundleIconFile. Параметры генерации включены в исходники.
  Отображение иконки проверено в стандартном окне «О Vela», сборка 3.
- В сборке 4 добавлена добровольная поддержка через Boosty автора.
  Проверены кнопки в боковой панели и меню «Справка», окно поддержки и переход
  на https://boosty.to/axira_dev/donate в Arc. Открывается форма доната Axira Dev;
  платёж не выполнялся. Платёжные данные в Vela не собираются.

## Автоматические проверки

10 модульных тестов Rust и 1 тест JSON-протокола прошли. Проверены пути,
аргументы без shell, изоляция переменных, сохранение данных, конкурентные записи,
жизненный цикл движка, Mach-O/PE-заголовки и loader symlink.
Жизненный цикл также проверяет запись DPI, сохранение значения и отклонение некорректного масштаба.
SwiftUI собран в строгом режиме Swift 6; приложение подписано ad hoc.

## Нативный движок

Wine 11.18, ARM64/ARM64EC, FEX. Все 59 Mach-O файлов движка проверены: ARM64.
Wine и Unix-модули FEX пересобраны с минимальной системой macOS 26.5.
GnuTLS с приватными зависимостями успешно загружен; gnutls_global_init вернул 0.

В новом пустом временном окружении выполнена итоговая проверка:

```text
PASS ARM64 loader, server and FEX registration
PASS native wineboot
PASS real Windows registry: LogPixels=192 (200%)
PASS real AMD64 PE: VELA_WINDOWS_X64_OK
PASS macOS P_TRANSLATED=false
PASS unsupported x86 rejected before launch
PASS scoped native wineserver stop
```

Тестовый EXE — собственная программа AMD64, собранная clang/LLD, без Windows SDK.
Она выполняет расчёт, проверяет результат и выводит маркер. Это внешний Intel PE,
а не встроенный ARM64 cmd.exe. Системный флаг P_TRANSLATED проверялся во время
работы теста. Сам измеритель проверен на контрольных ARM64 и x86_64 процессах: false/true.

Это подтверждает базовый запуск x64 без Rosetta. Совместимость конкретного
пользовательского ПО и будущих версий macOS требует отдельных проверок.

После изменения масштаба проверены реальное значение LogPixels через reg.exe,
сохранение 192 DPI в state.json и отображение 200% в SwiftUI. В пользовательском
нативном окружении применены 200%. Размер уже открытых окон Wine меняется после
их перезапуска; принудительной остановки пользовательского окружения не выполнялось.

## Ограничения

Движок без ограниченного разрешения Apple поддерживает только 64-битные программы.
Для него добавлен отдельный открытый патч: он не объявляет неподдерживаемые
32-битные архитектуры во время настройки. Лицензия патча — LGPL-2.1-or-later.
Временное отключение автоустановщиков Mono/Gecko действует только при инициализации.
Графические пакеты DirectX, Vulkan/MoltenVK и мультимедийные backends не установлены.
В журналах Wine остаются сообщения о неподдерживаемых необязательных устройствах и компонентах.

Исходники, собственный патч и параметры сборки указаны в
[build-native-runtime.ru.md](build-native-runtime.ru.md) и
[native-runtime-sources.json](native-runtime-sources.json).
