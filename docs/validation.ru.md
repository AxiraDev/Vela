# Проверка Vela 0.1.0

Дата: 23 октября 2026 года. Устройство: Apple M1, arm64, macOS 26.
Проверка выполнена локально с самостоятельным движком Wine.

## Сборка

- Rust 1.99.1, Swift 6.3.3, Xcode SDK macOS 26.5.
- Ядро собрано в release-режиме из закреплённых зависимостей.
- SwiftUI-интерфейс собран в строгом режиме Swift 6.
- Для UI явно задана минимальная цель macOS 14.0.
- Создан `.app`, выполнены локальная подпись ad hoc и проверка её структуры.
- Полные уведомления о лицензиях Rust-зависимостей включены в ресурсы приложения.

Работа на macOS 14/15 и Intel не проверялась. Указанная deployment target
подтверждает настройки сборки, а не заменяет тестирование на этих системах.

## Проверки Rust

Семь тестов:

1. Некорректный ID не позволяет выйти из папки окружений.
2. Пользовательские переменные не подменяют WINEPREFIX, WINEARCH, WINESERVER,
   PATH и параметры загрузки библиотек хоста.
3. Пробелы, `$` и `;` сохраняются в аргументах; macOS shell не используется.
4. Повреждённая или будущая версия state.json не заменяется пустыми данными.
5. Одновременные записи не теряют изменения.
6. Жизненный цикл с тестовым движком: подключение, создание, запуск, журнал,
   остановка и передача пути WINEPREFIX.
7. Завершённая строка JSON обрабатывается, даже если отправитель ещё не закрыл stdin.

## Настоящий Wine

Использована самостоятельная сборка Gcenx `wine-devel-11.18-osx64.tar.xz`.
Архив 190 974 384 байта. Локально вычисленный SHA-256 совпал с digest GitHub:

`aa0ea4c82e636ae7bca2076387cb0a5affa26509ad13f119ecd0d62bd7ba6f82`

[Исходный релиз поставщика](https://github.com/Gcenx/macOS_Wine_builds/releases/tag/11.18).

В новом отдельном тестовом каталоге выполнен `scripts/smoke_test.py`:

```text
PASS engine: wine-11.18
PASS wineboot
PASS system32: Windows EXE, shortcut, arguments, cwd, environment, log
PASS syswow64: Windows EXE, shortcut, arguments, cwd, environment, log
PASS scoped wineserver stop
All real-Wine integration checks passed.
```

Оба Windows cmd.exe напечатали ожидаемые маркеры и значение переданной переменной.
Тест запускал реальные 64- и 32-битные Windows PE-файлы. Это подтверждает базовую
работу выбранного движка и менеджера, но не совместимость произвольного ПО.

Для повторения нужен новый каталог тестовых данных и среда, разрешающая Wine
создавать локальные сокеты. Первый запуск внутри ограниченной среды исполнения
получил `wineserver: bind: Operation not permitted`. В обычном пользовательском
режиме инициализация и интеграционные проверки прошли. Ограничения безопасности
macOS глобально не менялись.

## Проверка интерфейса

В открытом Vela.app проверены:

- отображение зарегистрированного Wine;
- повтор инициализации после ошибки, переход окружения в состояние «готово»;
- добавление ярлыка на Wine Notepad;
- запуск ярлыка: процесс notepad.exe присутствовал;
- ручное сохранение WINEDEBUG и подтверждение в интерфейсе;
- чтение последнего журнала;
- подтверждение остановки и выполнение wineserver для выбранного окружения.

В стандартной папке `~/Library/Application Support/Vela` подготовлены самостоятельный
Wine, готовое окружение «Windows» и ярлык «Блокнот» для ознакомления. Исходная
тестовая копия в рабочей папке сохранена. Перенос — подготовка этой проверки,
а не реализованный пользовательский мастер миграции.
Тестовый Блокнот после проверки остановлен. Другие приложения не останавливались.

При повторном запуске из Documents обнаружено ожидание открытия файла данных.
Рабочая библиотека перенесена в Application Support; режим данных рядом с приложением
теперь включается только явно. В протокол добавлены явное завершение строки и
ограничение времени ожидания, в UI — индикатор загрузки и команда обновления.

## Не проверено

- Реальная установка произвольного стороннего MSI; диспетчеризация MSI проверена
  в тесте аргументов, но это не заменяет проверку Windows Installer на пакетах.
- Игры, DirectX, аппаратное ускорение, anti-cheat, мультимедиа и периферия.
- Сложные BAT/CMD-сценарии и особенности их quoting.
- Длительная нагрузка, нехватка места, аварийное выключение и восстановление.
- Notarization, Gatekeeper на другом компьютере, автообновление и миграция префиксов.

В журнале выбранной Wine-сборки есть диагностические сообщения OLE/setupapi
и сообщение об отключённом winemenubuilder. Базовые проверки прошли; отсутствие
ошибок в произвольных приложениях из этого не следует.
