# Vela · открытая оболочка Wine для macOS

Нативный интерфейс **SwiftUI** и отдельное ядро **Rust**. Первая рабочая версия
универсального менеджера Wine с ручными настройками. Лицензия ядра и интерфейса — MIT; патчи движка сохраняют лицензию Wine.

Самостоятельная реализация интерфейса и менеджера окружений с открытым исходным кодом.

## Архитектура движка

Vela 0.2 определяет ARM64/Intel по заголовку Mach-O и проверяет, что ARM64 Wine
использует ARM64 wineserver из той же сборки. Нативные движки показываются первыми.
У каждого окружения видна зависимость от Rosetta. Движок закреплён за окружением;
автоматического возврата с нативного движка на Intel нет.

Нативный вариант Wine + FEX установлен отдельно для macOS 26.5+.
Сборка без ограниченного разрешения Apple поддерживает **только 64-битные Windows-программы**.
В её `vela-runtime.json` стоит `supports_x86_32: false`; Vela отклоняет 32-битный
PE EXE до запуска. MSI и другие установщики могут включать 32-битные дочерние
программы, поэтому одной проверки заголовка для их совместимости недостаточно.

## Начать

1. Откройте `Vela.app` рядом с этим файлом.
2. В разделе «Движки Wine» добавьте распакованный `Wine Devel.app`, другую совместимую
   Wine.app, папку движка или файл `wine`. У движка должен быть собственный `wineserver`; путь внутри loader app определяется автоматически.
3. Нажмите «Новое окружение». Дождитесь создания диска C: и реестра.
4. Откройте EXE/MSI. После установки добавьте ярлык на установленную программу.
5. Версию Windows и другие параметры меняйте через «Настройки Wine».
   Переменные и DLL overrides задаются во вкладке «Настройки».

Открытые сборки: https://github.com/Gcenx/macOS_Wine_builds/releases

На Apple Silicon для старой проверенной сборки Gcenx x86_64 требуется Rosetta.
Она сохранена как прежний движок и не становится нативной после обновления интерфейса.
Rosetta не включается в Vela и автоматически не устанавливается.
У конкретной сборки Wine могут быть дополнительные требования, например GStreamer
для мультимедиа. Смотрите описание именно выбранного релиза.

### Хранение данных

По умолчанию библиотека находится в `~/Library/Application Support/Vela`.
Эта стандартная папка не требует доступа к защищённой папке Documents.
Подготовлены отдельные окружения «Windows» для прежнего Intel-движка
и «Windows 64 · без Rosetta» для нативного ARM64/FEX. В обоих есть ярлык Блокнота.
Для работы без Rosetta выбирайте новое окружение.
Откройте «Папка данных», чтобы найти библиотеку.

Для локального режима рядом с приложением можно переименовать `Portable.example`
в `Portable`: тогда данные будут в соседней папке `Data`. В защищённых каталогах
macOS может потребоваться доступ к папке; приложение не выдаёт его себе.
Маркер не переносит существующие данные автоматически.

Переменная `VELA_HOME` переопределяет путь данных для разработчика и тестов.

Внутри данных:

- `state.json` — список движков, окружений, ярлыков и переменных;
- `prefixes/<id>` — диск C:, реестр и пользовательские данные Windows;
- `logs/` — отдельный файл для каждой операции.
- `engine-backups/<id>` — копии перед сменой движка и сохранённые заменённые файлы.

Пути к движкам и программам абсолютные. Если переместить саму библиотеку или движок, зарегистрируйте
движок заново. Выбрать другой движок можно в настройках окружения; перенос библиотеки с переписыванием абсолютных путей не автоматизирован.

Окружение Wine не является защитной песочницей: Windows-программа работает с
правами вашего пользователя macOS. Кнопка «Остановить» завершает программы только
выбранного окружения и может привести к потере несохранённых изменений.

## Уже работает

- Несколько самостоятельных движков, проверка их запуска и версии.
- Смена движка существующего окружения с резервной копией и восстановлением.
- Создание 64-битных окружений, повтор после ошибки инициализации.
- Запуск EXE и MSI, сохранение ярлыков, аргументов и рабочей папки.
- Также предусмотрен запуск BAT/CMD через Windows cmd; сложное quoting требует
  отдельной проверки конкретных сценариев.
- `winecfg`, `regedit`, Windows-консоль и удаление Windows-программ.
- Ручные переменные окружения, включая `WINEDEBUG` и `WINEDLLOVERRIDES`.
- Масштаб интерфейса Windows от 100% до 300% во вкладке «Настройки»;
  для новых окружений на Retina предлагается 200%. Изменение сохраняется
  в реестре выбранного окружения и применяется после перезапуска Windows-программ.
- Остановка через `wineserver -k` с явным `WINEPREFIX`.
- Журнал последней операции и доступ ко всем журналам.
- Фоновая работа ядра: интерфейс не блокируется при wineboot.
- Запись state.json через временный файл, fsync и атомарное переименование;
  конкурентные записи сериализуются файловой блокировкой.

32-битные Windows-программы требуют движка с подходящей поддержкой WoW64.
Vela создаёт win64-префиксы; старые чистые win32-префиксы не поддерживаются.
Успешная передача процесса Wine ещё не означает, что программа полностью совместима.
Проверяйте окно программы и журнал.

## Поддержка разработки

Кнопка «Поддержать Vela» доступна в боковой панели и меню «Справка».
Она открывает окно добровольной поддержки; переход на платёжную страницу
выполняется только по нажатию пользователя. Публичный HTTPS-адрес автора
задаётся в `VelaDonationURL` в `macos/Info.plist` перед сборкой.
Пока адрес не указан, окно сообщает об этом, а переход недоступен.
Приложение не принимает и не хранит платёжные данные.

В этой сборке подключена страница автора:
https://boosty.to/axira_dev/donate

## Ограничения первой версии

Это предварительная версия универсального менеджера Wine.
Нет Winetricks, автоматического управления DirectX,
автообновлений, общего каталога снимков, live-статуса
дерева процессов и редактора уже созданных ярлыков. Для изменения ярлыка его
можно убрать и добавить заново. Журналы не ротируются автоматически.

Выбор движка хранится за окружением; Vela не скачивает и не обновляет его файлы.
Не заменяйте содержимое старой папки движка новой версией: храните версии рядом.
Криптографической проверки всех файлов локально выбранного движка пока нет.

Приложение собрано для Apple Silicon, macOS 14+. Intel можно собрать на Intel Mac,
но эта конфигурация здесь не проверялась. Подпись локальная ad hoc,
Developer ID и notarization пока не настроены. Сборка для разработки открывается
на этой машине; публичное распространение потребует отдельной подготовки релиза.

При аварийном завершении ядра может остаться `Data/state.lock`. Удаляйте его вручную
только убедившись, что другие экземпляры ядра не выполняют запись. Ошибки данных
не исправляются перезаписью пустой конфигурацией.

## Собрать из исходников

Нужны Rust с Cargo, Xcode/Command Line Tools и Swift 6. Сторонние Rust-зависимости
включены в `vendor/`, версии и контрольные суммы — в `core/Cargo.lock`.
Команды выполняются из корня проекта:

```sh
cargo test --locked --offline --manifest-path core/Cargo.toml
bash scripts/build.sh
open Vela.app
```

`scripts/build.sh` создаёт `.app`, кладёт внутрь ядро и уведомления о лицензиях,
затем подписывает локальной подписью в отдельной временной папке. Проверенный
архив приложения сохраняется в `build/Vela-preview.zip`. Приложение не использует сторонних Swift-пакетов.
Исходники Wine в этот исходный архив не входят: движок подключается отдельно.

Иконка приложения хранится в `macos/Assets/AppIcon.png`. При сборке
`scripts/build_icon.sh` создаёт набор размеров 16–1024 px и собирает `AppIcon.icns`
стандартными средствами macOS. Параметры генерации сохранены рядом с изображением.

## Каталог игровых лаунчеров в 0.3

Раздел «Игровые лаунчеры» скачивает официальный Windows-установщик, создаёт отдельное окружение и открывает мастер установки. После появления файлов клиента Vela добавляет ярлык. Доступны Steam, Epic Games, GOG GALAXY, Battle.net, EA app, Ubisoft Connect, Rockstar, Amazon Games, itch.io и Wargaming (EU). Riot представлен информационной карточкой из-за ограничений Vanguard.

Выберите движок с поддержкой разрядности установщика: многим загрузчикам нужен WoW64. Проверка наличия лаунчера не означает, что все его игры совместимы. Если адрес загрузки изменился, можно выбрать официальный установщик вручную. Подробности: [Launcher catalog](docs/launcher-catalog.md).

## Удаление окружений и язык интерфейса в 0.4

Удалить окружение можно на вкладке «Настройки» или через контекстное меню в боковой панели. После подтверждения Vela останавливает его программы и переносит запись в «Корзину Vela». Там окружение можно восстановить с файлами и настройками или удалить навсегда, чтобы освободить место. До окончательного удаления файлы остаются на диске; это отдельная корзина Vela, не корзина macOS. Движки Wine и внешние файлы сохраняются.

В «Настройках приложения» доступны русский, английский и «Как на устройстве». По умолчанию выбран системный вариант. Язык меняется сразу и сохраняется после перезапуска. Язык Windows-программ настраивается отдельно.

## Выбор движка в 0.4.1

На карточках выбора крупно показана разрядность Windows-программ: «32 и 64 бита», «Только 64 бита» или «Поддержка 32/64 бит не проверена». Отдельно указаны архитектура движка для Mac — Apple Silicon (ARM64) или Intel (x86_64) — и необходимость Rosetta. Intel-движок сам может быть 64-битным и при этом запускать Windows-программы обеих разрядностей через WoW64. Для 32-битного установщика заведомо несовместимые движки недоступны для выбора.

В 0.4.2 Intel Wine с поддержкой WoW64 отмечен как «Резервный для 32-битных программ». Его можно держать рядом с основным ARM64/FEX для старых приложений и установщиков. Он поддерживает 32 и 64 бита, но требует Rosetta на Apple Silicon. Сохранение файлов движка не гарантирует его работу после прекращения поддержки Rosetta. Текущая сборка ARM64/FEX не заменяет этот движок для 32-битных программ.

## Смена движка в 0.5

В настройках окружения нажмите «Сменить движок Wine…», выберите другую сборку и подтвердите переключение. Программы этого окружения закроются; предварительно сохраните работу. Установленные программы, файлы, ярлыки, переменные и масштаб сохраняются, пересоздавать окружение не нужно.

Перед изменениями Vela создаёт копию префикса и настроек в `engine-backups/<id>`, обновляет окружение новым Wine и проверяет запуск Windows. При ошибке выполняется попытка восстановления. После прерывания операции доступна кнопка «Вернуть состояние до смены движка…»; запуск блокируется до восстановления. Эту кнопку можно использовать и после успешного переключения.

Копии занимают место и не удаляются автоматически. Кнопка «Показать резервные копии» открывает их папку; окончательное удаление окружения также удаляет его копии. При восстановлении заменённые файлы остаются в подпапке `replaced-*`. Внешние файлы Mac, доступные по ссылкам Wine, не входят в копию. Предыдущий движок должен оставаться установленным. Смена движка не добавляет поддержку 32 бит в сборку, где её нет, и не гарантирует совместимость всех программ.
